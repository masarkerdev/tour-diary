# ভ্রমণসূচি ও ভ্রমণ বিবরণী

কৃষি সম্প্রসারণ অধিদপ্তরের কর্মকর্তাদের জন্য। প্রত্যেকে নিজের অ্যাকাউন্টে লগইন করে প্রতি মাসের অগ্রিম ভ্রমণসূচি, সংশোধিত ভ্রমণসূচি ও ভ্রমণ বিবরণী তৈরি, সংরক্ষণ ও প্রিন্ট করতে পারবেন।

## ফাইল

- `index.html` — পাতার গঠন (HTML)
- `style.css` — নকশা
- `app.js` — অ্যাপের সব কাজ
- `config.js` — Supabase-এর URL ও anon কী (শুধু এখানেই বসাতে হয়)
- `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — মোবাইলে অ্যাপ হিসেবে ইনস্টল ও ইন্টারনেট ছাড়া চালানোর জন্য

কোনো build লাগে না, চারটি ফাইল একই ফোল্ডারে থাকলেই চলে।
- `supabase-schema.sql` — ডাটাবেসের টেবিল ও নিরাপত্তা নিয়ম (প্রথম ধাপ)
- `supabase-upazila.sql` — উপজেলাভিত্তিক যৌথ তালিকা (দ্বিতীয় ধাপ)

## চালু করার ধাপ

### ১. Supabase প্রজেক্ট

1. supabase.com-এ নতুন প্রজেক্ট খুলুন (ফ্রি প্ল্যানে চলবে)।
2. **SQL Editor**-এ প্রথমে `supabase-schema.sql`, তারপর `supabase-upazila.sql` এর পুরোটা পেস্ট করে **Run** চাপুন।
3. **Authentication > URL Configuration**-এ **Site URL** হিসেবে আপনার সাইটের ঠিকানা দিন (ধাপ ৩ শেষে পাবেন)। নিশ্চিতকরণ ও পাসওয়ার্ড রিসেটের লিংক এখানেই ফেরত আসে।
4. **Project Settings > API** থেকে `Project URL` আর `anon public` কী কপি করুন।

### ২. কী বসানো

`config.js` খুলে এই দুটি মান বসান:

```js
window.APP_CONFIG = {
  SUPABASE_URL: 'https://xxxx.supabase.co',
  SUPABASE_ANON_KEY: 'eyJ...'
};
```

`anon` কী সাইটে প্রকাশ্যে থাকলেও সমস্যা নেই। Row Level Security চালু থাকায় প্রত্যেকে শুধু নিজের ডাটা দেখতে ও বদলাতে পারেন। **service_role কী কখনো এখানে বসাবেন না।**

### ৩. হোস্টিং

যেকোনো স্ট্যাটিক হোস্টিং চলবে। সহজ পথ:

- **Vercel / Netlify:** ফোল্ডারটা ড্র্যাগ করে দিলেই সাইট চালু।
- **GitHub Pages:** রিপোজিটরিতে `index.html` রেখে Pages চালু করুন।
- **নিজের সার্ভার (যেমন HortNet-BD):** ফাইলটা যেকোনো ফোল্ডারে রাখলেই হবে।

সাইটের ঠিকানা পেলে ধাপ ১.৩-এ Site URL বসাতে ভুলবেন না।

## ডেমো মোড

কী না বসিয়ে ফাইলটা খুললে অ্যাপ লগইন ছাড়া "ডেমো মোডে" চলে। তখন তথ্য শুধু ওই ব্রাউজারে থাকে। পরীক্ষা করে দেখার জন্য কাজে আসবে।

## ইমেইল নিশ্চিতকরণ

Supabase ডিফল্টভাবে নতুন অ্যাকাউন্টে ইমেইল নিশ্চিত করতে বলে। ফ্রি প্ল্যানে ঘণ্টায় অল্প কয়েকটি ইমেইল পাঠানো যায়, তাই অনেকে একসাথে অ্যাকাউন্ট খুললে দুটো উপায় আছে:

- **Authentication > Providers > Email**-এ "Confirm email" বন্ধ রাখা, অথবা
- **Authentication > SMTP Settings**-এ নিজের ইমেইল সার্ভিস (যেমন Gmail SMTP বা Brevo) যুক্ত করা।

## ব্যবহারের সংক্ষিপ্ত ধারা

1. **সেটআপ (একবার):** নাম, পদবি, রওয়ানার স্থান, ব্লক-এসএএও-দূরত্বের তালিকা, প্রতি মাসের নির্দিষ্ট ভ্রমণ (যেমন জেলা সভা)।
2. **মাসের শুরুতে:** মাস বাছাই, ছুটি ও ভ্রমণসংখ্যা দিয়ে "স্বয়ংক্রিয় সূচি তৈরি করুন"। প্রয়োজনমতো বদলে অগ্রিম সূচি নামিয়ে জমা দিন, তারপর **"অগ্রিম সূচি চূড়ান্ত করুন"**।
3. **মাসজুড়ে:** প্রতিটি ভ্রমণ খুলে প্রকল্প, প্রদর্শনীর কৃষক ও কাজ লিখুন। তারিখ বা ব্লক বদলালে সংশোধিত সূচিতে নিজে থেকে "পরিবর্তিত" দেখাবে। ভ্রমণ না হলে "বাতিল" দিন।
4. **মাসের শেষে:** সংশোধিত সূচি ও ভ্রমণ বিবরণী Word ফাইল হিসেবে নামান বা প্রিন্ট করুন।

## উপজেলাভিত্তিক তালিকা

- প্রথমবার লগইন করে সেটআপে জেলা বাছাই করলে সেই জেলার উপজেলাগুলো দেখায়। নিজের উপজেলায় চাপ দিলেই সদস্য, অনুমোদন লাগে না।
- উপজেলা তালিকায় না থাকলে যিনি প্রথমে তৈরি করবেন তিনি অ্যাডমিন হবেন। তাঁর তখনকার ব্লক ও তালিকা উপজেলার তালিকা হয়ে যাবে।
- রওয়ানার স্থান, ব্লক-এসএএও-দূরত্ব, প্রকল্প, উদ্দেশ্য, কাজের বাক্যাংশ আর নির্দিষ্ট ভ্রমণ উপজেলার সবার জন্য এক। শুধু অ্যাডমিন বদলাতে পারেন।
- নাম, পদবি, অনুমোদনকারী, সময় আর প্রতি মাসের সূচি প্রত্যেকের নিজের।
- অ্যাডমিন "উপজেলার সদস্য" অংশ থেকে অন্যকে অ্যাডমিন করতে পারেন। একমাত্র অ্যাডমিন অন্য সদস্য রেখে উপজেলা ছাড়তে পারেন না।

## মোবাইলে অ্যাপ ও ইন্টারনেট ছাড়া কাজ

- Android-এ Chrome দিয়ে সাইট খুললে উপরে "অ্যাপ ইনস্টল" বোতাম আসে (অথবা Chrome মেনু > Install app / Add to Home screen)। আইফোনে Safari > Share > Add to Home Screen।
- একবার ইন্টারনেট থাকা অবস্থায় লগইন করলে পরে ইন্টারনেট ছাড়াও অ্যাপ খোলে, আর আগের মাসগুলো দেখা ও নতুন তথ্য লেখা যায়।
- ইন্টারনেট ছাড়া লেখা পরিবর্তন ফোনে জমা থাকে ("অফলাইন: ফোনে রাখা আছে")। ইন্টারনেট এলে নিজে থেকে সার্ভারে যায়, তখন "সংরক্ষিত" দেখায়।
- না পাঠানো তথ্য থাকলে লগআউট করা যায় না, যাতে তথ্য না হারায়।
- একই মাস দুটো ডিভাইসে একসাথে অফলাইনে বদলালে শেষে যেটা সার্ভারে যাবে সেটাই থাকবে।
- নতুন সংস্করণ push করলে ইন্টারনেট থাকা অবস্থায় পরের বার খুললেই নতুনটা আসে। `sw.js`-এর `CACHE` নামের সংখ্যা বাড়ালে ফোনের পুরোনো কপি পুরো পরিষ্কার হয়।

## ডাটার গঠন

| টেবিল | কী থাকে |
|---|---|
| `profiles` | প্রত্যেক কর্মকর্তার সেটআপ (`data` jsonb) |
| `tour_months` | প্রতি মাসের ভ্রমণ, অগ্রিম সূচির স্থায়ী কপি (`user_id` + `ym`) |
| `upazilas` | উপজেলার যৌথ তালিকা (`district` + `name`, `data` jsonb) |
| `upazila_members` | কে কোন উপজেলার সদস্য, অ্যাডমিন নাকি সাধারণ সদস্য |
